Gestor de Tareas Colaborativo (TFG)

Aplicación Android desarrollada en Java para la gestión de tareas y subtareas con funciones de colaboración en tiempo real entre usuarios.

El proyecto permite:

Crear y organizar tareas jerárquicas
Gestionar subtareas
Compartir tareas con otros usuarios
Asignar responsabilidades
Utilizar calendario integrado y notificaciones
Personalizar la interfaz con modo claro y oscuro
Tecnologías Utilizadas
Java (Android Nativo)
Firebase Authentication
Cloud Firestore
Material Design 3
RecyclerView
SharedPreferences
